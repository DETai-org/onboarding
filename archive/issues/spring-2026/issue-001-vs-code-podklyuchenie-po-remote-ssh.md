# Issue #1: VS Code подключение по Remote-SSH

# VS Code подключение по Remote-SSH 

## Цель
Подключиться к серверу по SSH из VS Code (Remote-SSH) и открыть папку проекта на сервере, чтобы редактировать файлы и запускать команды.

---

## 0) Что нужно заранее

- Доступ к серверу (IP + пользователь)  
- Возможность зайти в консоль сервера через DigitalOcean 
- Установленный VS Code на Windows (см. #7 )

---

## 1) Открой VS Code на Windows


## 2) Установить расширение Remote - SSH

> **Зачем это нужно:**
> Расширение **Remote - SSH** позволяет VS Code подключаться к серверу по SSH и работать с файлами **на сервере**, как будто они находятся на компьютере.

### 2.1. Открыть магазин расширений VS Code

1. Открой VS Code
2. В левой боковой панели нажми на иконку **Extensions**
   (или нажми сочетание клавиш `Ctrl + Shift + X`)
3. Вверху появится строка поиска расширений


### 2.2. Найти расширение Remote - SSH

1. В строке поиска введи:

   ```
   Remote - SSH
   ```
2. В списке результатов найди расширение:

   * **Remote - SSH**
   * Автор: **Microsoft**
   * Иконка: синяя с символом `>_`

⚠️ Важно:

* именно **Remote - SSH**, а не `Remote Explorer`, `Remote Tunnels` и т.п.
* автор должен быть **Microsoft**


### 2.3. Установить расширение

1. Нажми на расширение **Remote - SSH**
2. В открывшейся карточке нажми **синюю кнопку `Install`**
3. Дождись окончания установки

Ожидаемый результат:

* кнопка `Install` заменится на `Disable` / `Uninstall`
* расширение считается установленным


### 2.4. Что изменилось после установки

После установки **Remote - SSH**:

* в VS Code появятся команды для подключения к серверу по SSH
* VS Code сможет:

  * использовать SSH-ключи
  * открывать папки на сервере
  * запускать команды **на сервере**
* станет доступна команда:

  ```
  Remote-SSH: Connect to Host...
  ```

⚠️ Пока подключения нет — это нормально.
Мы настроим его **на следующих шагах**.


### 2.5. Подготовка к следующему шагу

На следующем шаге мы:

* откроем терминал **внутри VS Code**
* создадим SSH-ключ **на этом компьютере**
* подготовим доступ к серверу без пароля

👉 Переходи к **пункту 3**.

---

## 3) Создать SSH-ключ для этого компьютера

> **Зачем это нужно:**
> SSH-ключ — это способ идентифицировать твой компьютер.
> Сервер “запоминает” этот ключ и в дальнейшем пускает тебя **без пароля**, что необходимо для стабильной работы VS Code Remote-SSH.

---

### 3.1. Открыть терминал внутри VS Code (локальный компьютер)

Мы будем создавать SSH-ключ **на компьютере**, а не на сервере.

1. Убедись, что VS Code открыт.
2. В верхнем меню VS Code нажми:

   ```
   Terminal → New Terminal
   ```
3. В нижней части окна появится терминал.

Правильный признак, что всё ок:

* строка начинается с `PS C:\Users\...>`
* это означает **локальный Windows-терминал**, а не сервер

⚠️ Если ты видишь `root@...` — это сервер, **ключ здесь создавать нельзя**.

---

### 3.2. Запустить команду генерации SSH-ключа

В терминале VS Code **скопируй и вставь** команду:

```powershell
ssh-keygen -t ed25519 -C "laptop-vscode"
```

Нажми **Enter**.

Что делает эта команда:

* `ssh-keygen` — утилита для создания SSH-ключей
* `-t ed25519` — современный и безопасный тип ключа
* `-C "laptop-vscode"` — комментарий, чтобы было понятно, **какой компьютер** создал ключ (можно заменить на любое название)

---

### 3.3. Ответить на вопросы генератора ключей

После запуска команды терминал задаст несколько вопросов.

#### Вопрос 1: куда сохранить ключ

Ты увидишь примерно такое сообщение:

```text
Enter file in which to save the key (C:\Users\<USER>\.ssh\id_ed25519):
```

👉 **Важно:**
Мы НЕ используем `id_ed25519`, чтобы не путаться.

1. Удали предложенное имя
2. Впиши путь вручную:

```text
C:\Users\<USER>\.ssh\laptop-vscode
```

3. Нажми **Enter**

---

#### Вопрос 2: passphrase (пароль на ключ)

Терминал спросит:

```text
Enter passphrase (empty for no passphrase):
```

👉 Для онбординга:

* **ничего не вводи**
* просто нажми **Enter**

Потом будет:

```text
Enter same passphrase again:
```

👉 Снова нажми **Enter**

---

### 3.4. Проверить, что ключ успешно создан

Если всё прошло правильно, ты увидишь сообщение вида:

```text
Your identification has been saved in C:\Users\<USER>\.ssh\laptop-vscode
Your public key has been saved in C:\Users\<USER>\.ssh\laptop-vscode.pub
```

Это значит:

* 🔐 приватный ключ: `laptop-vscode` (никому не показываем)
* 🔓 публичный ключ: `laptop-vscode.pub` (его будем копировать на сервер)

---

## 4) Добавить публичный SSH-ключ на сервер (через DigitalOcean)

> **Зачем:**
> Сервер должен “узнать” твой компьютер.
> Для этого мы добавляем **публичный ключ** в настройки сервера.

---

### 4.1. Скопировать публичный ключ на компьютере

В том же терминале VS Code выполни команду:

```powershell
type $env:USERPROFILE\.ssh\laptop-vscode.pub
```

Нажми **Enter**.

1. В терминале появится **одна длинная строка**, начинающаяся с:

   ```
   ssh-ed25519 ...
   ```
2. Выдели **всю строку целиком**
3. Скопируй её (Ctrl+C)

⚠️ Копировать нужно **одной строкой, полностью**.

---

### 4.2. Зайти в консоль сервера через DigitalOcean

1. Открой браузер
2. Зайди в панель **DigitalOcean**
3. Перейди в нужный Droplet 
4. Нажми кнопку **Console / Access → Launch Console**

Откроется браузерная консоль сервера с приглашением:

```text
root@ubuntu-...:~#
```

---

### 4.3. Добавить ключ в `authorized_keys` на сервере

В консоли сервера **по очереди** выполни команды:

```bash
mkdir -p ~/.ssh
chmod 700 ~/.ssh
nano ~/.ssh/authorized_keys
```

Откроется редактор nano

Файл authorized_keys может уже содержать другие строки — это нормально.
Каждая строка в этом файле — это один SSH-ключ.

⚠️ Важно:

не удаляй существующие строки

новый ключ нужно добавить в самый конец файла

Как вставить ключ в nano

С помощью стрелок на клавиатуре перемести курсор:

вниз (↓)

до самой последней строки файла

Поставь курсор на новую пустую строку внизу

Вставь скопированную строку публичного ключа:

правый клик мышью
или

Shift + Insert

Как сохранить файл и выйти

Нажми:

Ctrl + O


(O — как Output)

Нажми Enter (подтвердить сохранение)

Нажми:

Ctrl + X


(выход из редактора)

После этого ты вернёшься в терминал сервера.

После этого выполни:

```bash
chmod 600 ~/.ssh/authorized_keys
```

---

### 4.4. Что мы сделали на этом шаге

* 🔐 Компьютер создал SSH-ключ
* 🔓 Публичный ключ добавлен на сервер
* 🔑 Сервер теперь доверяет этому компьютеру
* 🚫 Пароль для SSH больше не нужен
* ✅ VS Code сможет подключаться стабильно

## 4) Проверить SSH-доступ с компьютера (обязательный шаг)

> **Зачем это нужно:**
> Прежде чем подключать VS Code к серверу, нужно убедиться, что **обычное SSH-подключение работает**.
> Это позволяет сразу понять: проблема в доступе к серверу или в настройках VS Code.

---

### 4.1. Открыть терминал внутри VS Code (локальный)

1. Убедись, что VS Code открыт
2. В верхнем меню нажми:

   ```
   Terminal → New Terminal
   ```
3. Внизу откроется терминал

Правильный признак:

* строка начинается с:

  ```
  PS C:\Users\...
  ```
* это означает, что ты работаешь **на своём компьютере**, а не на сервере

---

### 4.2. Подключиться к серверу по SSH

В терминале VS Code выполни команду:

```powershell
ssh root@165.22.115.62
```

(используй IP своего сервера, если он другой)

---

### 4.3. Ожидаемое поведение

При первом подключении ты можешь увидеть сообщение:

```text
Are you sure you want to continue connecting (yes/no)?
```

👉 Напиши:

```
yes
```

и нажми **Enter**.

Если SSH-ключ добавлен правильно, произойдёт следующее:

* ❌ пароль **не запрашивается**
* ✅ ты сразу попадаешь на сервер
* появится приглашение вида:

  ```
  root@ubuntu-...:~#
  ```

---

### 4.4. Выйти из SSH-сессии

Чтобы вернуться обратно на компьютер, выполни:

```bash
exit
```

Ты снова увидишь:

```
PS C:\Users\...
```

---

### 4.5. Если что-то пошло не так

* Если SSH **просит пароль** — значит ключ не добавлен или добавлен неверно
* Если появляется `Permission denied` — вернись к шагу 3
* Если SSH **вообще не подключается** — не переходи дальше, сначала почини доступ

👉 Пока шаг 4 не работает — **шаги 5–6 делать нельзя**.

---

## 5) Настроить SSH config (чтобы VS Code подключался стабильно)

> **Зачем это нужно:**
> Файл `~/.ssh/config` позволяет:
>
> * задать серверу понятное имя
> * указать, **какой именно SSH-ключ использовать**
> * запретить попытки входа по паролю
> * сделать подключение VS Code стабильным

---

### 5.1. Открыть файл SSH config

1. В VS Code нажми:

   ```
   F1
   ```
2. В появившемся поле введи:

   ```
   Remote-SSH: Open SSH Configuration File
   ```
3. Выбери файл:

   ```
   C:\Users\<USER>\.ssh\config
   ```

Если файл пустой — это нормально.
Если в нём уже есть другие записи — **не удаляй их**.

---

### 5.2. Добавить конфигурацию сервера

В конец файла добавь блок:

```sshconfig
Host london-server
    HostName 165.22.115.62
    User root
    IdentityFile C:\Users\<USER>\.ssh\laptop-vscode
    IdentitiesOnly yes
    ServerAliveInterval 30
    ServerAliveCountMax 6
```

⚠️ Важно:

* `Host london-server` — это **локальное имя сервера**, можно использовать именно его
* путь к `IdentityFile` должен совпадать с именем ключа из шага 3
* строка `IdentitiesOnly yes` обязательна — без неё VS Code может снова просить пароль

---

### 5.3. Сохранить файл

1. Нажми:

   ```
   Ctrl + S
   ```
2. Убедись, что файл сохранён (нет индикатора изменений)

---

### 5.4. Что мы сделали на этом шаге

* дали серверу понятное имя: `london-server`
* жёстко указали, **какой SSH-ключ использовать**
* отключили попытки входа по паролю
* подготовили среду для Remote-SSH

---

## 6) Подключиться к серверу через VS Code Remote-SSH

> **Зачем это нужно:**
> На этом шаге VS Code подключается к серверу по SSH и разворачивает там свой агент.
> После этого VS Code фактически начинает работать **прямо на сервере**.

---

### 6.1. Открыть командную палитру VS Code

1. В VS Code нажми:

   ```
   F1
   ```

   или:

   ```
   Ctrl + Shift + P
   ```
2. Откроется строка команд в верхней части окна

---

### 6.2. Запустить подключение Remote-SSH

1. В строке команд введи:

   ```
   Remote-SSH: Connect to Host...
   ```
2. Нажми **Enter**
3. В списке хостов выбери:

   ```
   london-server
   ```

---

### 6.3. Выбрать платформу сервера

При первом подключении VS Code может спросить:

> **Select platform for the remote host**

👉 Выбери:

```
Linux
```

---

### 6.4. Дождаться подключения

Дальше VS Code автоматически:

* подключится по SSH
* установит **VS Code Server** на сервер
* настроит туннель связи

Это может занять **10–30 секунд**.

Ожидаемый результат:

* откроется **новое окно VS Code**
* в левом нижнем углу будет написано:

  ```
  SSH: london-server
  ```

⚠️ Если на этом этапе появляется запрос пароля или ошибка — **не продолжай дальше**, вернись к шагам 4–5.

---

### 6.5. Что важно понимать

* Это **не обычный SSH-терминал**
* На сервере запущен отдельный процесс VS Code Server
* Все файлы, которые ты видишь в этом окне, находятся **на сервере**

---

## 7) Открыть папку проекта на сервере

> **Зачем это нужно:**
> После подключения VS Code ещё не знает, **с какой папкой на сервере ты хочешь работать**.

---

### 7.1. Открыть папку

1. В новом окне VS Code (где написано `SSH: london-server`) нажми:

   ```
   File → Open Folder
   ```
2. Откроется список папок **на сервере**
3. Выбери нужную папку проекта
   (например: `/root`, `/root/project-name` и т.п.)
4. Нажми **OK**

---

### 7.2. Доверие к папке

VS Code может спросить:

> **Do you trust the authors of the files in this folder?**

👉 Нажми:

```
Yes / Trust
```

---

### 7.3. Ожидаемый результат

* в левой панели появится дерево файлов сервера
* ты можешь:

  * открывать файлы
  * редактировать код
  * запускать команды в терминале
* терминал VS Code теперь выполняет команды **на сервере**, а не на компьютере


# 🎉 На этом этапе подключение считается полностью завершённым.
