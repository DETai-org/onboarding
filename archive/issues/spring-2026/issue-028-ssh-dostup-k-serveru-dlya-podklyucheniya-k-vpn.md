# Issue #28: SSH-доступ к серверу для подключения к VPN

## 🎯 Цель туториала

В этом туториале вы настроите доступ к серверу DETai через SSH и подготовите браузер Google Chrome к работе через наш VPN-маршрут.

После прохождения туториала вы сможете:

- создать SSH-ключ на своём компьютере;
- отправить публичную часть ключа администратору;
- подключиться к серверу DETai через терминал;
- запустить VPN-подключение через SSH;
- настроить расширение Proxy SwitchyOmega в рабочем профиле Google Chrome;
- переключать браузер между режимами:
  - прямой интернет без VPN;
  - системный VPN;
  - подключение через SSH/VPN-сервер DETai.

> [!IMPORTANT]  
> Все действия с браузером нужно выполнять именно в рабочем профиле Google Chrome которые мы создавали.

---

## 1. Что такое SSH-ключ

SSH-ключ — это способ безопасного подключения к серверу без обычного пароля.

При создании ключа на компьютере появляются две части:

```text
private key  → приватная часть, остаётся только у вас
public key   → публичная часть, её можно отправить администратору
````

> [!WARNING] Никогда не отправляйте приватный ключ
> Приватный ключ нельзя отправлять в Telegram, ClickUp, GitHub, Google Docs, ChatGPT или куда-либо ещё.
> Администратору отправляется только публичная часть ключа — файл, который заканчивается на `.pub`.


---

## 2. Откройте терминал Windows

Нажмите:

```text
Win + R
```

В открывшееся окно введите:

```text
cmd
```

Нажмите:

```text
Enter
```

Откроется терминал Windows.

---

## 3. Создайте SSH-ключ

Введите команду, которая соответствует вашему username.

### Any-Kaith

```bash
ssh-keygen -t ed25519 -C "any-kaith"
```

### VsePsy

```bash
ssh-keygen -t ed25519 -C "vsepsy"
```

### Katrin-tekil

```bash
ssh-keygen -t ed25519 -C "katrin-tekil"
```

Когда терминал спросит, куда сохранить ключ, можно просто нажать:

```text
Enter
```

Когда терминал спросит passphrase, можно снова нажать:

```text
Enter
```

И ещё раз:

```text
Enter
```

> [!TIP]
> На этом этапе создаётся пара ключей. Один файл будет приватным, второй публичным.
>
> Публичный файл обычно называется:
>
> ```text
> id_ed25519.pub
> ```

---

## 4. Показать публичную часть ключа

После создания ключа введите команду:

```bash
type %USERPROFILE%\.ssh\id_ed25519.pub
```

Терминал покажет длинную строку, которая начинается примерно так:

```text
ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAI...
```

Скопируйте всю строку полностью.

> [!IMPORTANT]
> Строка публичного ключа должна быть скопирована целиком и без переносов.
>
> Она начинается с `ssh-ed25519` и обычно заканчивается вашим комментарием, например:
>
> ```text
> any-kaith
> ```

---

## 5. Отправьте публичный ключ в командный Telegram-чат

Отправьте в командный Telegram-чат только публичную часть ключа.

Пример сообщения:

```text
Мой публичный SSH-ключ:

ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAI... any-kaith
```

После этого администратор добавит ваш публичный ключ на сервер.

---

## 6. Подключитесь к серверу

Когда администратор подтвердит, что ключ добавлен, снова откройте терминал.

Нажмите:

```text
Win + R
```

Введите:

```text
cmd
```

Нажмите:  Enter


Теперь введите свою команду подключения.

### Any-Kaith

```bash
ssh any-kaith@165.22.115.62
```

### VsePsy

```bash
ssh vsepsy@165.22.115.62
```

### Katrin-tekil

```bash
ssh katrin-tekil@165.22.115.62
```

При первом подключении терминал может спросить, доверяете ли вы этому серверу.

Введите:

```text
yes
```

и нажмите:

```text
Enter
```

Если подключение прошло успешно, вы окажетесь внутри сервера.

Обычно это видно по тому, что строка терминала меняется и появляется имя пользователя и сервера. Если вы видите зелёную строку с именем пользователя и сервера, значит вы уже на сервере.

Сохраните свою команду подключения в Obsidian в файл команда под рукой, поскольку эта команда будет часто и вами использоваться.

---


## 7. Найдите команду 🌐 Наш VPN  в Obsidian

Откройте Obsidian.

В левом поле Obsidian у вас должен быть закреплён файл:

```text
Система под рукой
```

Это базовый файл, который вы добавляли во время прохождения туториала Obsidian: устновка и базовая настройка #22 


В этом файле сохранена команда для подключения к нашему VPN 

Скопируйте эту команду и вставьте её в терминал.

После запуска этой команды на вашем компьютере появится локальный proxy-порт, через который браузер сможет выходить в интернет через наш сервер.

---

## 9. Установите Proxy SwitchyOmega в рабочий профиль Chrome

Откройте Google Chrome именно в рабочем профиле:

Перейдите в Chrome Web Store В поиске введите:

```text
Proxy SwitchyOmega
```

Установите расширение:

```text
Proxy SwitchyOmega (V3)
```

После установки откройте страницу расширений Chrome.

Для этого можно ввести в адресную строку:

```text
chrome://extensions/
```

Найдите:

```text
Proxy SwitchyOmega (V3)
```

Убедитесь, что расширение включено.

Также включите закрепление расширения на панели браузера.

> [!TIP]
> Расширение лучше сразу закрепить на панели Chrome, чтобы быстро переключать режимы подключения.
>
> Если расширение не видно справа от адресной строки, нажмите на значок пазла в Chrome и закрепите Proxy SwitchyOmega.

---

## 10. Создайте профиль `Chain-SSH-HY2`

Откройте настройки Proxy SwitchyOmega.

Создайте новый proxy profile и назовите его:

```text
Chain-SSH-HY2
```

Название важно: используйте именно это имя, чтобы у всех участников команды профиль назывался одинаково.

---

## 11. Настройте proxy server

В профиле `Chain-SSH-HY2` заполните поля так:

```text
Protocol: SOCKS5
Server: 127.0.0.1
Port: 1081
```

То есть:

* в поле `Protocol` выберите `SOCKS5`;
* в поле `Server` вставьте `127.0.0.1`;
* в поле `Port` вставьте `1081`.

См. скриншот 1.

> [!IMPORTANT]
> `127.0.0.1` означает ваш собственный компьютер.
>
> `1081` — это локальный порт, через который браузер будет подключаться к SSH/VPN-туннелю.

Если в настройках есть кнопка сохранения или применения изменений, нажмите её.

Обычно это может называться:

```text
Apply changes
```

---

## 12. Включите профиль `Chain-SSH-HY2`

После того как:

* SSH/VPN-команда запущена в терминале;
* профиль `Chain-SSH-HY2` создан в Proxy SwitchyOmega;
* в профиле указан `SOCKS5`, `127.0.0.1`, `1081`;

нажмите на значок Proxy SwitchyOmega справа от адресной строки Chrome.

Выберите:

```text
Chain-SSH-HY2
```

См. скриншот 2.

Теперь браузер будет использовать подключение через SSH/VPN-сервер DETai.

---

## 13. Проверьте IP-адрес

Откройте сайт для проверки IP.

Например, можно найти в Google:

```text
check my ip
```

Если всё настроено правильно, IP должен определяться как лондонский.

Это значит, что браузер работает через наш SSH/VPN-маршрут.

---

## 14. Как переключать режимы

В Proxy SwitchyOmega есть несколько режимов.

`Chain-SSH-HY2` Используйте этот режим, Когда обычный VPN наш **Happ не работает**

 `System Proxy` Используйте этот режим, когда включили Happ

 `Direct` Используйте этот режим, если хотите, чтобы браузер работал напрямую, без VPN. Но лучше для нашего рабочего аккаунта вообще не использовать браузер без VPN.

**См. скриншот 2.**

> [!TIP]
> Если сайт не открывается, сначала проверьте, какой режим выбран в Proxy SwitchyOmega.
>
> Часто проблема не в сайте, а в том, что выбран не тот proxy-профиль.

---

## 15. Типовой порядок запуска

Когда всё уже настроено, обычный порядок работы будет таким:

1. Открыть рабочий профиль Chrome `Dev`.
2. Открыть терминал через `Win + R` → `cmd` → `Enter`.
3. Подключиться к серверу через SSH.
4. Открыть Obsidian.
5. Найти закреплённый файл `Система под рукой`.
6. Скопировать команду подключения к VPN.
7. Вставить команду в терминал и запустить.
8. В Chrome выбрать Proxy SwitchyOmega → `Chain-SSH-HY2`.
9. Проверить IP.
10. Начать работу.

Вы сможете:

* безопасно подключаться к серверу;
* запускать SSH/VPN-подключение;
* переключать браузер в режим `Chain-SSH-HY2`;
* проверять, что браузер выходит в интернет через лондонский IP;
* возвращаться к `System Proxy` или `Direct`, когда SSH/VPN-режим не нужен.
