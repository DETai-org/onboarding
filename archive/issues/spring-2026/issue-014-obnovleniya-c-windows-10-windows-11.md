# Issue #14: Обновления c Windows 10 → Windows 11

ТРЕБУЕТ ОФОРМЛЕНИЯ


идём по шагам. Ниже — самый понятный и безопасный сценарий обновления c Windows 10 → Windows 11 с сохранением файлов и программ. Я дам два пути: через «Центр обновления Windows» и через «Помощник по установке Windows 11» (рекомендую его, если в обновлениях кнопку не предлагают). В конце — что проверить после апгрейда.

---

# 0) Подготовка (5 минут)

1. **Сделай резервную копию важного** (на всякий случай): `D:\Obsidian`, «Документы», «Рабочий стол».
    
2. **Питание и интернет.** Подключи ПК к электросети и оставь стабильный интернет.
    
3. **Освободи место на диске C:** желательно иметь свободными ≥ 25 ГБ.
    
4. **Проверь требуемые флаги (быстро):**
    
    - **TPM 2.0:** `Win+R` → `tpm.msc` → в окне должно быть «TPM готов к использованию» и «Версия спецификации: **2.0**».
        
    - **Secure Boot/UEFI:** `Win+R` → `msinfo32` → смотри **«Режим BIOS: UEFI»** и **«Состояние безопасной загрузки: Включено»**.
        
        > Если Secure Boot выключен — это не критично на этапе проверки; при необходимости включается в BIOS позже.
        

---

# 1) Способ А — через «Центр обновления Windows» (если появится предложение)

1. **Параметры** → **Обновление и безопасность** → **Центр обновления Windows**.
    
2. Нажми **Проверить наличие обновлений**.
    
3. Если увидишь «Обновиться до Windows 11» → нажми **Загрузить и установить**, согласись с условиями.
    
4. Двигайся по мастеру до конца (ПК сам несколько раз перезагрузится).
    

> Если кнопки с Windows 11 нет — переходи к способу Б.

---

# 2) Способ Б — «Помощник по установке Windows 11» (рекомендую)

Этот инструмент делает именно **обновление**, сохраняя файлы, программы и настройки.

1. С официального сайта Microsoft скачай **Помощник по установке Windows 11** (Windows 11 Installation Assistant).
    
2. Запусти файл **от имени администратора** (правый клик → «Запуск от имени администратора»).
    
3. Прими лицензию и нажми **Обновить**.
    
4. Жди, пока помощник:
    
    - скачает компоненты,
        
    - проверит систему,
        
    - запустит установку.  
        ПК перезагрузится несколько раз — это нормально.
        
5. Войдёшь в учётную запись — готово.
    

---

# 3) Альтернатива — Media Creation Tool (через ISO/USB)

Если удобнее обновиться с ISO:

1. Скачай **Media Creation Tool** для Windows 11.
    
2. Запусти → выбери **Создать установочный носитель** → **ISO-файл**.
    
3. Когда ISO будет готов, щёлкни по нему правой кнопкой → **Подключить**.
    
4. На появившемся виртуальном диске запусти **`setup.exe`**.
    
5. В мастере выбери **«Сохранить личные файлы и приложения»** и продолжи.
    

---

# 4) Что проверить после обновления

1. **Активация:** `Win+R` → `cmd` →
    
    ```
    slmgr /xpr
    ```
    
    В окошке должно быть «Постоянная активация прошла успешно».
    
2. **Обновления драйверов:** Параметры → Центр обновления → **Дополнительные обновления** — поставь доступные.
    
3. **Эмодзи:** нажми `Win+.` — откроется панель эмодзи. Стиль должен стать таким же, как на твоём ноутбуке.
    
4. **Наши задачи синхронизации сохранились:**
    
    - Показать задачи:
        
        ```
        schtasks /query /fo LIST /v | find "Obsidian"
        ```
        
    - Пробный запуск:
        
        ```
        schtasks /run /tn "Obsidian Pull at Logon"
        schtasks /run /tn "Obsidian Push at Logoff"
        ```
        
    
    Если обе отрабатывают — всё отлично.

## Частые вопросы

- **Файлы и программы сохранятся?**  
    Да, при _обновлении_ (оба способа выше) всё остаётся на месте. Чистая установка нужна только если сам её выберешь.
    
- **Если активация «слетит»?**  
    У тебя цифровая бессрочная лицензия — всё должно остаться активированным. В редких случаях достаточно снова войти под тем же Microsoft-аккаунтом или ввести ключ, если он у тебя есть.
    
- **Что если не проходит проверка TPM/Secure Boot?**  
    Обычно на системах последних лет TPM 2.0 и Secure Boot есть, просто Secure Boot может быть выключен в BIOS. Это решается включением в BIOS/UEFI. Если столкнёшься — напишешь, подскажу, куда зайти у твоей модели.
