# GitHub: Вход в организацию

## Контекст

Прежде чем начать выполнение данного туториала, советуем. Освежить информацию о том, [что такое GitHub и какую роль, как инструмент он выполняет в нашей экосистеме](https://detai-org.github.io/Knowledge_substrate/ru/ecosystem/Tools/%F0%9F%9B%A0GitHub/)

На этом этапе GitHub нужен нам не только как платформа для кода, но и как одна из сред прохождения онбординга.

Именно здесь находятся tutorial issues, под которыми можно оставлять комментарии, задавать вопросы по шагам и фиксировать своё продвижение. То есть GitHub здесь выступает не как что-то сугубо техническое для программистов, а как пространство взаимодействия, обратной связи и постепенного вхождения в рабочую среду.

База знаний уже отдельно объясняет, [что такое GitHub и чем он отличается от Git](https://detai-org.github.io/Knowledge_substrate/ru/ecosystem/Tools/%F0%9F%9B%A0GitHub/). Этот туториал показывает, что именно вам нужно сделать practically, чтобы войти в GitHub.

После этого шага вы будете не просто читать туториалы со стороны, а сможете взаимодействовать с ними как участник процесса.

## Что вы освоите?

Создадите GitHub-аккаунт.
 Станете частью GitHub Organization DETai-org.
Получите доступ к разным репозиториям
Сможете оставлять комментарии под любым 🎓 Tutorial (issues) 
Подготовите себе точку входа в песочницу, где позже можно будет безопасно попробовать простые действия с кодом и взаимодействие с Codex.

## Цель 🎯

Цель этого туториала — помочь вам создать GitHub-аккаунт и войти в GitHub как в одну из рабочих сред экосистемы.


## Что вам понадобится для прохождения туториала

  (мы устанавливали его на предыдущем шаге, здесь оно понадобится для подключения двухфакторной аутентификации в GitHub).


## Пошаговые действия

### Шаг 1: Создайте GitHub-аккаунт

1. Перейдите на GitHub.
2. Нажмите **Sign up**.
3. Зарегистрируйте новый аккаунт.
4. Используйте свою новую почту
5. Для username используйте свой ник (как в ClickUp) 


### Шаг 2: Проверьте, что аккаунт действительно работает

1. Завершите регистрацию.
2. Убедитесь, что можете войти в аккаунт.
3. Если GitHub попросит подтвердить почту — подтвердите её.
4. После входа проверьте, что вы попадаете в свой профиль и всё открывается нормально.

### Шаг 3: Настройте базовый профиль

1. Добавьте аватар (тот же что и везде используете)

2. Нажмите на иконку профиля в правом верхнем углу → Settings (см. 1 СКРИН) Появится окно с меню в левой части, там:

2.1  Выберите раздел `account` → нажмите на `Change username` Пропишите свой ник, как и в других местах. Например, как в ClickUp.

_Если ник-name уже занят, придумайте другой ник - логически он был похож на имя, которая используется в команде. И ник, который будет свободен, нужно будет дальше применять везде, в том числе и в ClickUp и в других инструментах, чтобы ник был везде одинаковый. Он будет использовать через `@` для обращения к вам._

2.2 Выберите раздел  `Public profile` → Впишите свое любое имя, можно использовать Emoji 

2.3 Выберите раздел `Password and authentication` → в блоке Two-factor authentication нажмите Enable two-factor authentication, выберите вариант с приложением-аутентификатором, отсканируйте QR-код через Google Authenticator (его мы уже устанавливали в предыдущем туториале), введите шестизначный код и обязательно сохраните recovery codes.

2.4 Выберите раздел `Notifications` → в блоках `Watching` и `Participating, @mentions and custom` установите вариант `On GitHub, Email`, чтобы получать уведомления и внутри GitHub, и на почту. После этого зайдите в репозиторий, нажмите `Watch`  И там выберите `All Activity`, чтобы не пропускать новые комментарии и активность в issue. (см. СКРИН 3)


### Шаг 4: Пришлите в общий чат ваш GitHub username

После этого вас  добавят в **GitHub Organization DETai-org**.  Примите приглашение в организацию

После этого вы станете участником GitHub Organization DETai-org.


### Шаг 5: Оставьте тестовый комментарий под этим tutorial (issue)


Прокрутите вниз до поля комментария и оставьте короткий тестовый комментарий.

Например:

- `Тестовый комментарий: GitHub подключён`
- `Проверка связи`

Это нужно не ради формальности, а чтобы убедиться, что у вас есть доступ и комментарии работают;

или оставьте полноценный комментарий Того что можно было бы изменить в этом ту tutorial **принцип этого смотри в**   #3 


### Шаг 6: Установите GitHub на телефон

После того как вы создали GitHub-аккаунт и вошли в него с компьютера, сразу установите приложение **GitHub** на телефон и войдите в тот же аккаунт. (см. СКРИН 2 )

Через приложение удобно:

- читать tutorial issues;
- отслеживать комментарии и уведомления;
- держать контакт с рабочей средой даже тогда, когда вы не за компьютером.

Во многих случаях читать туториалы через приложение на телефоне даже удобнее и приятнее, чем через браузер: интерфейс более собранный, а сами issues хорошо подходят для такого формата чтения.

Если приложение не открывается или работает нестабильно, при необходимости попробуйте использовать тот же VPN, который мы уже настраивали ранее.

## Результат 🎯

После выполнения всех шагов вы:

1. Создадите и настроите GitHub-аккаунт.
2. Будете добавлены в GitHub Organization DETai-org.
3. Получите доступ к репозиториям
4. Сможете оставлять комментарии.
