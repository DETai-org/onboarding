# Issue #19: Голосовой ввод на компе через Superwhisper

# Голосовой ввод на компьютере через Superwhisper

## Что вам понадобится для прохождения туториала

- компьютер на Windows;
- рабочий микрофон;
- стабильный интернет для установки и первичной настройки;

## Контекст

На предыдущем шаге мы уже настроили голосовой ввод **в браузере** через расширение **Voice In - Speech-to-Text Dictation**.

Но в рабочем процессе нам нужен голосовой ввод не только в браузере, а **во всей системе в целом**: в десктопном Telegram, ClickUp, в документах, заметках и других приложениях на компьютере.

Для этого мы используем **Superwhisper** — приложение, которое позволяет превращать голос в текст **в разных сайтах и приложениях Windows**.

## Что вы освоите?

Получите универсальный инструмент для голосового ввода вне браузера.

## Цель

Цель этого туториала — настроить на компьютере системный голосовой ввод, который можно использовать в разных приложениях, а не только в браузере.

После прохождения этого шага у вас появится удобный способ быстро надиктовывать текст в рабочей среде DET / DETai.

## Пошаговые действия

### Шаг 1. Перейдите на сайт Superwhisper

Откройте сайт: `https://superwhisper.com`

На главной странице введите свою почту в поле ввода и нажмите **Download**.

Если ниже есть вариант **Skip and download**, можно использовать и его — но базовый сценарий для нового пользователя начинается с ввода почты и нажатия **Download**.

---

### Шаг 2. Запустите установщик

После скачивания откройте установочный файл **Superwhisper Setup**.

На первом экране нажмите **Next**.

На экране выбора папки установки ничего менять не нужно — оставьте путь по умолчанию и снова нажмите **Next**.

Дождитесь завершения установки.

---

### Шаг 3. Пройдите первичный onboarding внутри приложения

После запуска приложения нажмите **Get Started**.

Если приложение покажет экран с предложением подключиться к Discord, ничего подключать не нужно — просто нажмите **Got it**.

---

### Шаг 4. Настройте микрофон

Когда появится экран **Setup microphone**, выберите свой микрофон и нажмите **Continue**.

Если у вас один основной микрофон, достаточно просто выбрать его и продолжить.

---

### Шаг 5. Откройте настройки режимов

После завершения onboarding откройте главное окно приложения.

Слева нажмите **Modes**. В блоке **Default** откройте настройки режима.

Выберите базовую конфигурацию для русского голосового ввода

Установите следующие настройки:

- **Preset:** `Voice`
- **Voice Model:** `Standard` (там нужно немного времени чтобы оно прогрузилось)

💡 _Примечание: для того, чтобы выбрать это, нажми на маленькую шестеренку, смотри **1 скрин.**_

Чтобы проверить, что Superwhisper настроен правильно, откройте любое текстовое поле в приложении например телеграм, поставьте туда курсор, нажмите `Ctrl + Space`, продиктуйте 1–2 предложения по-русски и нажмите  `Ctrl + Space` ещё раз; если текст вставился и русский распознался нормально, значит базовая настройка работает.

### Шаг 5.  Настрой автозапуск при включении компьютера.

1. Добавление ярлыка в папку автозагрузки

Добавить ярлык на Superwhisper в папку автозагрузки Windows:

Нажми Win+R для открытия окна "Выполнить".
Введи команду `shell:startup` и нажми Enter. Это откроет папку автозагрузки.
Найди ярлык приложения Superwhisper Для этого перейди в месторасположение приложения. ( См. СКРИНШОТ 2)
 Скопирую из той папки ярлык в папку автозагрузки.


## Результат

После прохождения этого туториала у вас будет настроен системный голосовой ввод на компьютере через **Superwhisper**.

Теперь вы сможете использовать голос для ввода текста не только в браузере, но и в разных приложениях Windows — например, в **ClickUp**, **Telegram Desktop**, документах и других рабочих средах.
