# Issue #23: Закладки в Google Chrome

## Контекст 🎓

На первом шаге вы создали отдельный Google-аккаунт для работы в экосистеме DET
Теперь этот аккаунт нужно немного **оснастить**, чтобы у вас сразу была базовая навигация по важным инструментам и ресурсам.

Смысл этого tutorial простой:

* не собирать всё вручную с нуля;
* сразу получить базовую структуру закладок;
* сделать браузер удобной рабочей точкой входа.

В репозитории `onboarding` уже лежит готовый файл:

`Bookmarks.html`

Он содержит подготовленную структуру закладок, которую можно импортировать в Chrome.

---

## Что нужно сделать

1. скачать файл `Bookmarks.html` из репозитория;
2. импортировать его в Google Chrome;
3. проверить, что закладки появились;
4. вынести самые часто используемые ссылки на домашнюю страницу браузера.

---

## Шаг 1. Скачайте файл Bookmarks.html

Перейдите в раздел **_Code_** данного репозитория. `onboarding`  и скачайте файл:

Чтобы скачать файл нужно нажать на него и в правом верхнем углу нажать на иконку загрузки смотри на **3 скриншот**

Сохраните его в любое удобное место на компьютере, чтобы потом выбрать его при импорте.

---

## Шаг 2. Откройте менеджер закладок в Chrome

Откройте Google Chrome.

Дальше есть два варианта:

### Вариант 1

Нажмите сочетание клавиш: **Ctrl + Shift + O**  

### Вариант 2

Откройте меню Chrome и перейдите в раздел закладок вручную.

После этого у вас откроется страница управления закладками.

---

## Шаг 3. Импортируйте файл с закладками

На странице закладок нажмите на **три точки** в правом верхнем углу.

Далее выберите пункт: **Import bookmarks**  (См. **1 скриншот**)

И укажите скачанный ранее файл `Bookmarks.html`.

После этого Chrome импортирует структуру подготовленных закладок.

---

## Шаг 4. Проверьте, что закладки появились

После импорта у вас должны появиться папки и ссылки, которые были заранее подготовлены для онбординга.

Это базовая рабочая навигация, чтобы нужные ресурсы были под рукой и не приходилось собирать их по памяти заново.

Если всё прошло правильно, в верхней панели браузера появятся закладки и папки, которые можно использовать сразу.

---

## Шаг 5. Настройте домашнюю страницу под себя

Теперь сделайте ещё один маленький, но важный шаг: вынесите на домашнюю страницу браузера те ссылки, которыми вы будете пользоваться чаще всего.

Обычно это как минимум:

* **ChatGPT**
* **ClickUp**

При желании можно добавить и другие часто используемые инструменты.

В результате домашняя страница может выглядеть примерно так, как показано на **2 скриншоте**.

Смысл этого шага в том, чтобы самые частые действия были буквально в одном клике от вас.

_И да не забудьте добавить обои с нашей символикой_ 🤩😎

### Установите фирменные обои для Google

Чтобы ваш рабочий профиль Google сразу ощущался частью экосистемы DET, рекомендуем скачать и установить фирменные обои для домашней страницы Google. Это не обязательный шаг, но он помогает сделать браузер более «своим» и сразу зафиксировать наши брендовые цвета и символику.

Для этого в репозитории onboarding откройте файл Google Wallpaper.png, нажмите на него, затем нажмите на три точки справа вверху и выберите Download (см. скриншот 4).

## Шаг 6. Настройте запуск рабочего профиля Chrome

После того как закладки импортированы, важно настроить не только навигацию, но и сам способ запуска браузера. Это помогает каждый раз быстрее возвращаться к работе и не собирать рабочую среду заново.

На предыдущем шаге мы настроили рабочее пространство **внутри Chrome**: закладки, домашнюю страницу, визуальное оформление и быстрый доступ к нужным ресурсам. Теперь нужно сделать так, чтобы Chrome при запуске помогал продолжать работу, а не каждый раз открывался как пустое окно.

Откройте настройки запуска Chrome. Для этого можно вставить в адресную строку:

```text
chrome://settings/onStartup
```

На открывшейся странице будет несколько вариантов запуска браузера:

| Вариант | Что означает | Когда удобно использовать |
|---|---|---|
| `Open the New Tab page` | Chrome открывается с новой пустой вкладки | если вы хотите каждый раз начинать с чистого экрана |
| `Continue where you left off` | Chrome открывает вкладки, которые были открыты перед закрытием | если вы хотите продолжать работу с того места, где остановились |
| `Open a specific page or set of pages` | Chrome каждый раз открывает заранее заданный набор страниц | если вы хотите всегда стартовать с одного и того же набора инструментов |

Для рабочего профиля обычно удобнее выбрать:

```text
Continue where you left off
```

Так Chrome будет восстанавливать предыдущие вкладки: ChatGPT, ClickUp, GitHub, документы и другие рабочие страницы, которые были открыты в прошлый раз.

> [!TIP]
> Если вы хотите, чтобы браузер каждый раз открывался с фиксированного набора страниц, можно выбрать `Open a specific page or set of pages` и добавить туда, например, ChatGPT, ClickUp и GitHub.

## Шаг 7. Проверьте, что Chrome запускается именно в рабочем профиле

Если на компьютере используется несколько Chrome-профилей, важно убедиться, что для работы используется отдельный рабочий профиль, а не личный.

Это помогает разделить личные вкладки, пароли, расширения и рабочие инструменты.

Откройте настройки профиля Chrome:

1. нажмите на аватар профиля в правом верхнем углу браузера;
2. выберите управление профилем или значок редактирования;
3. проверьте, что вы находитесь в нужном рабочем профиле;
4. при необходимости включите опцию `Create desktop shortcut ` (см. **Скриншот 5**)

Эта настройка создаёт ярлык на рабочем столе, который открывает Chrome сразу в выбранном профиле. Это удобно, потому что не нужно каждый раз выбирать профиль вручную при запуске браузера. 

_В результате можно сделать отдельный ярлык для рабочего Chrome-профиля и использовать его как основную точку входа в рабочую среду._

## Дополнительно. Настройте быстрый запуск рабочих окон через PowerToys 💡

Этот шаг не является обязательным, но может заметно ускорить начало работы.

Если предыдущие шаги помогают настроить рабочее пространство **внутри браузера**, то PowerToys позволяет подняться на уровень выше и настроить рабочее пространство **самого компьютера**.

То есть можно заранее собрать набор окон, который нужен для начала работы, и запускать его одним кликом. 😎

Например, можно сделать отдельную рабочую область `База включения`

```text
Obsidian + Happ / VPN + Terminal
```

Это удобно, потому что в начале работы обычно нужно всегда:

- включить VPN;
- открыть Obsidian, где храниться команды;
- открыть терминал для подключения к нашему VPN.

Такой набор можно сохранить как отдельную рабочую область и запускать сразу после включения компьютера.

### Как создать рабочую область в PowerToys

1. Скачайте и установите Microsoft PowerToys с https://github.com/microsoft/PowerToys/releases/tag/v0.98.1
2. Откройте PowerToys.
3. Перейдите в раздел:

```text
Рабочие области
```

4. Нажмите кнопку:

```text
Создать рабочую область
```

После этого появится специальный режим захвата рабочей области: экран будет визуально выделен рамкой, а PowerToys начнёт отслеживать, какие окна вы открываете и как вы их располагаете.

В этот момент нужно подготовить рабочую сцену:

1. закройте все окна, которые не должны открываться вместе с этой рабочей областью;
2. откройте только нужные приложения;
3. расположите их на экране так, как вам удобно;
4. задайте нужный размер каждому окну;
5. завершите создание рабочей области, нажав кнопку, которую предложит PowerToys.

> [!IMPORTANT]
> Если вы читаете этот tutorial в браузере, а браузер не должен входить в создаваемую рабочую область, перед завершением настройки его нужно закрыть. Иначе PowerToys может добавить его в сценарий запуска.

### Пример базовой рабочей области

Для базового включения можно открыть:

```text
Obsidian
Happ (VPN)
Terminal
```

Такой сценарий помогает быстро выйти в рабочий режим: открыть заметки, включить VPN и подготовить терминал.

После сохранения PowerToys может создать ярлык на рабочем столе. Тогда весь набор будет запускаться одним кликом.

---

### Добавить еще один сценарий.

Как добавить Chrome именно с рабочим профилем

Если вы хотите добавить в рабочую область Chrome, важно убедиться, что запускается именно рабочий профиль, а не окно выбора профиля.

Для этого сначала откройте нужный рабочий профиль Chrome и вставьте в адресную строку:

```text
chrome://version/
```

Найдите строку:

```text
Profile Path
```

В конце пути будет указано название папки профиля, например Default или Profile 2

Эту часть нужно использовать в настройках рабочей области PowerToys.

В редакторе рабочей области раскройте приложение `Google Chrome` и найдите поле:

```text
Аргументы CLI
```
**См. Скриншот 6**

Если ваш рабочий профиль называется `Default`, тогда пример будет таким:

```text
--profile-directory="Default" 
```

Так PowerToys будет запускать не просто Chrome, а Chrome сразу в нужном рабочем профиле

## Ещё одна дополнительная фишка 😎

Создание отдельного приложения из любой веб-страницы

Chrome может сделать из сайта отдельное “приложение”, которое будет открываться отдельным окном.

Например открытой ChatGPT и сделай так:

1. Нажми на три точки справа в Chrome.
2. Наведи на:

```text
Cast, save, and share
```

3. Выбери:

```text
Install page as app
```

4. Подтверди установку.

После этого ChatGPT появится как отдельное приложение в Windows: его можно будет найти через `Пуск`, закрепить на панели задач 
_Это дополнение может стать удобной и полезной фичей для пользователей, которые хотят максимально быстро работать с конкретными веб-сервисами, не открывая браузер с несколькими вкладками._ (см. **скриншот 7**)

## Результат выполнения 🎯

После выполнения этого tutorial у вас будет:

- импортирована базовая структура закладок;
- настроена более удобная навигация по рабочим ресурсам;
- подготовлена домашняя страница браузера для повседневной работы;
- выбран удобный режим запуска рабочего Chrome-профиля;
- при необходимости создан ярлык для быстрого входа именно в рабочий профиль;
- дополнительно настроены рабочие области PowerToys для запуска нескольких приложений одним кликом.

То есть браузер перестаёт быть просто “пустым окном интернета” и становится рабочей точкой входа в контур онбординга: с закладками, нужным профилем, сохранёнными вкладками и быстрым запуском основных инструментов.

А PowerToys позволяет собрать ещё один уровень выше — не только рабочий браузер, но и рабочий стол Windows: VPN, Obsidian, терминал, Chrome, ClickUp и другие инструменты, которые можно запускать как готовую рабочую сцену.
