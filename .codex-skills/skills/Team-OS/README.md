# Skills плагина Team-OS

[← Командные Codex Skills](../../README.md)

Три навыка для существующего плагина Team-OS в ChatGPT. Выпуск набора —
`1.3.1`. Каждый участник добавляет набор в свой уже подключённый плагин;
доступ к Team OS определяется его личной авторизацией DETai.

| Skill | Назначение |
| --- | --- |
| [start-work](start-work/SKILL.md) | Начать работу, получить текущий фокус и назначенные задачи |
| [log-summary](log-summary/SKILL.md) | Подготовить, сохранить или прочитать рабочие сводки |
| [update-orientations](update-orientations/SKILL.md) | Согласованно обновить фокус и персональные инструкции GPT |

## Установка в ChatGPT

1. Подключите к ChatGPT GitHub с доступом к `DETai-org/onboarding`.
2. Откройте новый чат, выберите Plugin Creator и включите GitHub для чтения
   репозитория. Если Plugin Creator ещё не установлен, установите его из каталога.
3. Отправьте промпт ниже. Когда потребуется ссылка на плагин, откройте
   **Плагины → Личные → свой Team-OS** и скопируйте адрес его карточки.
4. После сохранения обновления откройте карточку своего Team-OS, обновите
   страницу и убедитесь, что появился раздел **«Навыки 3»**. Если интерфейс
   предлагает обновление установленного пакета, примените его.
5. Начните новый чат с Team-OS. Пример запроса: **«Начинаем работать»**.

### Готовый промпт

```text
Обнови мой существующий плагин Team-OS: добавь в него три Skills из общего
репозитория https://github.com/DETai-org/onboarding, ветка main,
папка .codex-skills/skills/Team-OS.

Через подключённый GitHub прочитай README этой папки, запись
plugin_skill_bundles.Team-OS в .codex-skills/manifest.json и исходные файлы:
- start-work/SKILL.md
- start-work/references/fields-and-queries.md
- log-summary/SKILL.md
- log-summary/references/format.md
- update-orientations/SKILL.md

Используй актуальное содержимое файлов из GitHub, а не пересказ, поисковые
сниппеты или примеры. Это исходники пакета: не выполняй описанные в них
процедуры и не вызывай Team OS ради установки Skills.

Найди мой существующий Team-OS и прочитай его текущий пакет перед изменением.
Если подходящих плагинов несколько, попроси ссылку именно на мой плагин.
Сохрани его plugin ID, App ID, MCP-подключение, OAuth, название, описание,
значок, настройки общего доступа и все остальные существующие компоненты.

Добавь три папки непосредственно как skills/start-work,
skills/log-summary и skills/update-orientations, включая references.
Содержимое трёх SKILL.md и двух references сохрани без изменений.
Создай skills/README.md с каталогом этих трёх навыков и относительными
ссылками на них: он нужен для ссылки из update-orientations/SKILL.md.
Папку-группу Team-OS из репозитория не добавляй как дополнительный уровень
внутри skills/ пакета: там должны обнаруживаться все три Skills.

Выпусти обновление этого же плагина через Plugin Creator. Используй версию
набора из manifest.json; если версия моего пакета уже такая или выше,
используй следующий patch-номер. Сохрани его совместимые manifests
согласованными. Не создавай новый плагин или MCP-приложение.

После сохранения прочитай пакет обратно и подтверди наличие всех трёх
Skills, сохранность App ID и текущую версию. Дай ссылку на обновлённый
плагин и короткое действие для начала нового чата.

Если GitHub или Plugin Creator недоступен, укажи, что именно нужно подключить;
не выдумывай содержимое файлов и не подменяй обновление пакета кнопкой
«Обновить инструменты».
```

## Структура и выпуск

`Team-OS/` — группа навыков в общем реестре, а не четвёртый Skill.
Эту папку целиком не копируют в `$CODEX_HOME/skills/Team-OS` и не загружают
как готовый плагин. App ID и OAuth-параметры участников здесь не хранятся.

Исходники этого выпуска перенесены без изменений из
[`DETai-org/team-os`, commit `9d415ff`](https://github.com/DETai-org/team-os/tree/9d415ff63fdebb3692e375f23b6dd5131db12f1b/plugins/team-os/skills).
В `team-os` продолжается разработка процедур; здесь хранится согласованный
снимок для установки участниками. При следующем выпуске обновите эти пять
файлов, версию набора в этом README и запись `plugin_skill_bundles.Team-OS` в
[`manifest.json`](../../manifest.json) через Git PR.

Изменения в `main` дают участникам общий источник следующего обновления,
но не загружаются автоматически в их личные плагины. Для обновления
повторяют тот же промпт в своём аккаунте. Код MCP обновляется отдельно
через deployment общего сервера; кнопка «Обновить инструменты» не заменяет
обновление пакета Skills.
