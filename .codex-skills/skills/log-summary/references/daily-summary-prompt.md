# Итог дня и КВЦ

Используй только когда пользователь завершает день или явно просит сводку.

```text
Собери уже записанные дневные work blocks в краткий итог для ClickUp.

Сохрани только уникальные результаты; не пересказывай каждый блок второй раз.
Сформулируй одно предложение «Итог дня»: что стало готово или возможно.
Затем дай одну КВЦ дня — человеческим языком и без технических деталей.

Если какой-либо уровень работы действительно представлен, его можно отметить:
операционный, координационный или концептуальный. Пустые уровни не выводи.
Не добавляй callout-блоки, эмодзи или пояснения ради оформления.
```
