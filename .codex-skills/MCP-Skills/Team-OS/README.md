# Skills плагина Team-OS

[← Командные Codex Skills](../../README.md)

Три навыка для существующего плагина Team-OS в ChatGPT. Выпуск набора —
`1.3.1`. Каждый участник добавляет набор в свой уже подключённый плагин;
доступ к Team OS определяется его личной авторизацией DETai.

| Skill | Назначение |
| --- | --- |
| [start-work](start-work/SKILL.md) | Начать работу, получить текущий фокус и назначенные задачи |
| [log-summary](log-summary/SKILL.md) | Подготовить, сохранить или прочитать рабочие сводки |
| [update-orientations](update-orientations/SKILL.md) | Согласованно обновить фокус и персональные инструкции GPT |

## Установка в ChatGPT

1. Подключите к ChatGPT GitHub с доступом к `DETai-org/onboarding`.
2. Откройте новый чат, выберите Plugin Creator и включите GitHub для чтения
   репозитория. Если Plugin Creator ещё не установлен, установите его из каталога.
3. Скопируйте промпт из [заметки Team OS](https://team.detai-x.com/notes/a6257580-a67a-489d-9ad4-03fcf21f25a3) и отправьте его в чат.
   Когда потребуется ссылка на плагин, откройте
   **Плагины → Личные → свой Team-OS** и скопируйте адрес его карточки.
4. После сохранения обновления откройте карточку своего Team-OS, обновите
   страницу и убедитесь, что появился раздел **«Навыки 3»**. Если интерфейс
   предлагает обновление установленного пакета, примените его.
5. Начните новый чат с Team-OS. Пример запроса: **«Начинаем работать»**.

Готовый промпт хранится в заметке Team OS:
[«Установка и обновление Skills плагина Team-OS»](https://team.detai-x.com/notes/a6257580-a67a-489d-9ad4-03fcf21f25a3).

## Структура и выпуск

`Team-OS/` — группа навыков в общем реестре, а не четвёртый Skill.
Эту папку целиком не копируют в `$CODEX_HOME/skills/Team-OS` и не загружают
как готовый плагин. App ID и OAuth-параметры участников здесь не хранятся.

Исходники этого выпуска перенесены без изменений из
[`DETai-org/team-os`, commit `9d415ff`](https://github.com/DETai-org/team-os/tree/9d415ff63fdebb3692e375f23b6dd5131db12f1b/plugins/team-os/skills).
В `team-os` продолжается разработка процедур; здесь хранится согласованный
снимок для установки участниками. При следующем выпуске обновите эти пять
файлов, версию набора в этом README и запись `plugin_skill_bundles.Team-OS` в
[`manifest.json`](../../manifest.json) в том же Git-коммите.

Изменения в `main` дают участникам общий источник следующего обновления,
но не загружаются автоматически в их личные плагины. Для обновления
повторяют тот же промпт в своём аккаунте. Код MCP обновляется отдельно
через deployment общего сервера; кнопка «Обновить инструменты» не заменяет
обновление пакета Skills.
